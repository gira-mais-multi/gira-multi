# Gira+ Multi

Versão modificada e não oficial do [Gira+](https://github.com/rt-evil-inc/gira-mais), alterada desde outubro de 2026 para guardar várias contas na mesma aplicação e trocar entre elas sem terminar sessão. Só Android.

*Unofficial modified version of [Gira+](https://github.com/rt-evil-inc/gira-mais), changed since October 2026 to keep several accounts in one app and switch between them without logging out. Android only.*

## Instalar / Install

Descarregue o APK em [Releases](../../releases), ou adicione o endereço deste repositório ao [Obtainium](https://github.com/ImranR98/Obtainium) para receber atualizações. Cada versão é a última versão do Gira+ com estas alterações.

*Download the APK from [Releases](../../releases), or add this repository's address to [Obtainium](https://github.com/ImranR98/Obtainium) to get updates. Each release is the latest Gira+ release with these changes.*
